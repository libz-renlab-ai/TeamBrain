# PR #213 fix plan — /review iteration 1

## 1. Task description

Address actionable findings from the always-on Claude adversarial subagent run on PR #213's diff (issue #160 graceful skip in warmup). Five findings get applied; two are intentionally deferred with rationale.

### Applied

| # | Severity | File | Fix |
|---|---|---|---|
| #1 | HIGH (9/10) — backward compat | `packages/cli/src/commands/warmup.ts` | Write `pid: 0` for skipped state (placeholder convention). Older teamagent readers that don't know `"skipped"` fall through to the `"downloading"` branch; `isPidAlive(0)` returns true (per `writeInitialPlaceholder`), so they see a soft `"downloading"` rather than a hard `stale_downloading` FAIL. Test asserts `state.pid === 0`. |
| #2 | HIGH (8/10) — detection drift | `packages/cli/src/commands/warmup.ts` (`defaultHaveVectorOptionals`) | Port the Wave-9 P3 `pkgRoot` walk from `init.ts:299-308`: walk up from `import.meta.url` to the nearest enclosing `package.json` and use that as `knownRoots[0]` instead of `dist/commands`. Fixes false negatives on custom `npm config set prefix`, Volta, yarn berry PnP. |
| #4 | MEDIUM (7/10) — race | `packages/cli/src/commands/warmup.ts` | Before writing `status:"skipped"`, read existing state. If `status === "downloading"` AND `isPidAlive(pid)`, leave it alone — log a one-line note instead. Prevents foreground manual `teamagent warmup` from trampling a detached download spawned by init/postinstall. New test exercises the race. |
| #7 | LOW (8/10) — log ordering | `packages/teamagent/postinstall.mjs` | Move `recordSetupStatus(...)` BEFORE the multi-line stderr banner in both skip arms, so a SIGINT / EPIPE between log and banner can't leave the log line missing. |
| (extra from critical pass §V1) | CRITICAL — enum completeness | `packages/cli/src/commands/doctor.ts` | Add explicit `r.reason === "skipped"` branch returning `status:"skip"` with "vector deps 未安装" detail. Without this, doctor falls through to `"state file malformed" FAIL`. New test in `warmup-state.test.ts` covers `describeWarmupReadiness` returning `reason:"skipped"`. |
| docs | n/a — completeness gap | `CHANGELOG.md` | Add `## Unreleased / Fixed / Issue #160` entry. The change is user-visible: exit code, log shape, doctor row all change. |
