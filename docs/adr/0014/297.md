# 19. audio 线：#296/#297/#310 必须统一成 `audio` event source

## Grill 问题

录音是个人记忆、项目证据、日报输入，还是异常输入？

## 可选答案

A. 个人记忆
B. 项目证据
C. 日报输入
D. 异常输入
E. audio 是 event source，用途由 plugin 决定

## 裁决

选 **E**。

```txt
AudioRecordingStarted
AudioRecordingStopped
AudioUploaded
AudioTranscriptReady
AudioSummaryReady
```

plugins 决定用途：

```txt
RecordingMemoryPlugin:
  进入 personal/team memory

ProjectEvidencePlugin:
  挂到 project/issue/PR

DailySummaryPlugin:
  可选进入日报

AbnormalDetectorPlugin:
  可选扫描 blocker/risk/stuck
```

#296 说明两个独立子系统都用了 “recording”：一个是 `teamagent recording import|search|show|inject|metrics|benchmark` 的 Recording Memory，另一个是 `teamagent record start|stop|import` 的 digital-twin audio recorder，而且后者还上传到 `/v1/recordings`；issue 明确指出这会让用户混淆。citeturn148789view0turn148789view1

所以命名裁决：

```txt
新命名：
  teamagent audio start
  teamagent audio stop
  teamagent audio import
  teamagent audio devices

API:
  /v1/audio-recordings
  /v1/events

事件：
  AudioRecordingStarted
  AudioTranscriptReady

兼容：
  teamagent record start -> alias to teamagent audio start
  /v1/recordings -> deprecated alias
```

# 20. #297：默认麦克风，第一次确认设备，提供 escape hatch

## Grill 问题

`teamagent audio start` 默认录什么？

## 可选答案

A. 默认麦克风
B. 默认系统声音
C. 默认 mic + system
D. 第一次强制选择
E. 默认麦克风 + 第一次确认 + `--input/--device`

## 裁决

选 **E**。

#297 指出 macOS 默认 first input mic，Linux 默认 PulseAudio default，但 Windows 默认 `audio=virtual-audio-capturer`，也就是系统 loopback；这不录自己的麦克风，而且还依赖一个非 Windows 内置组件。#297 还指出目前 `parseRecordArgs` 只有 `--id` 和 `--label`，没有 `--device`，所以用户无法覆盖设备。citeturn148789view2turn148789view3

新命令：

```bash
teamagent audio start
teamagent audio start --input mic
teamagent audio start --input system
teamagent audio start --input both
teamagent audio start --device \"USB Microphone\"
teamagent audio devices
```

默认行为：

```txt
第一次运行：
  list devices
  choose first mic / confirm
  save local default

之后：
  teamagent audio start -> mic

高级：
  --input system / both
  --device exact name
```

这满足 #297 的“默认录麦克风，loopback opt-in via --device”。citeturn148789view3
