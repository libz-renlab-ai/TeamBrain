§1 Problem

Claude Code 没有记忆。
你纠正它的每一句话，下次都白说。

不是 CLAUDE.md。是会自己进化的活规则库。

  • AI 第 5 次想用 moment，你第 5 次说"换 dayjs"。
  • 新会话开始，上次的约定统统失效，又得从头解释。
  • CLAUDE.md 越写越长，AI 该犯的错还是犯。
  • 团队里每人调教的经验，没有办法共享给下一个人。

§4 Install

安装（30 秒）

curl -fsSL https://raw.githubusercontent.com/libz-renlab-ai/TeamBrain/release/install.sh | sh
teamagent init

开源 · 自托管 · 无云端依赖 — 你的代码、规则、历史只在本机。

§5 How it works

工作原理

对话发生 → Stop hook 捕获纠正信号 → 提炼 avoidance 规则入库 → 下次 PreToolUse 命中时拦截并给出原因。

§6 Team & tools

进阶功能

team-layer 团队规则共享（xsync）
每个人纠正 AI 的经验，变成全团队复用的规则。新人加入即继承团队经验，无需重复调教。
多工具适配（Claude Code / Cursor / Codex）
Claude Code 已支持；MCP Server 与 Cursor compiler 开发中（NOT YET）。规则库通用，不锁定单一工具。
卸载 + 数据位置
数据存于 ~/.teamagent/，纯 JSON，可人工检查。teamagent uninstall 移除 hooks，rm -rf ~/.teamagent 删除所有规则数据。
