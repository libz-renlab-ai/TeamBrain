Claude Code 的问题

  • 每个新会话都是白板，所有规则要从零编写
  • 规则写在文件里，但 AI 根本不主动读
  • 团队成员各写各的，经验无法积累
  • 装了一堆工具，不知道哪条规则在管它们
team-layer：团队规则层

团队共享的规则沉淀在 team-layer，每个成员开箱即用，不需要重新配置。

多工具：4 通道适配

PreToolUse / UserPromptSubmit / Stop analyze / AttributionBus 四个通道同时适配，跨工具统一行为。

uninstall：一键卸载

删除 .claude/ 目录即可完全卸载，不留残余，不影响原有工作流。
