## Grill 决策摘要 — issue #280

### Scope（一次修 3 个 bug，atomic claim）
1. 主 bug：Windows 上 `spawn('claude', shell:false)` 撞旧 npm prefix 残留 → analyze 学习哑火
2. 附带 bug：`bin-session-start.cjs` 硬 require 已被 #158 移除的 optional peer dep（`web-tree-sitter` 等）→ SessionStart 崩 → updater 不跑
3. 隐蔽 bug：`doctor` 只看文件存在性，不真跑 hook → 用户假绿

### 修法

**主 bug — `packages/adapters/src/llm/claude-code-client.ts:171` `defaultSpawner`**
- Windows 上 `shell: true`，其他平台保持 `shell: false`
- 安全前提：`command="claude"` 硬编码 + args 全是固定字面量 + prompt 走 stdin → 无 shell injection 风险
- 故意不走 issue body 推荐的 `require.resolve('@anthropic-ai/claude-code/package.json')` —— 验证发现 `packages/teamagent/package.json` 不依赖该包（v0.11.0 dep 列表里没有），用户机器解析必失败
- 故意不引入 `cross-spawn` —— 不增加依赖；`shell:true` 在已知 args 安全场景下足够

**附带 bug — `packages/cli/src/bin-session-start.ts` import 链审计**
- 找到所有硬 import 的 optional dep 入口（web-tree-sitter / tree-sitter-* / xenova 间接路径）
- 改成 lazy `try { require(...) } catch { return null }` 工厂函数，与 `ast-context.ts:initAstMatcher` 既有 fallback 协议对齐
- chaos test：mock 缺失 dep 状态后 spawn hook，断言 exit 0 + stderr 印保守模式 banner

**Doctor — `packages/cli/src/commands/doctor.ts` 增加新检查项**
- 真 spawn `node <path>/bin-session-start.cjs`，喂最小合法 SessionStartHookInput JSON
- 5s timeout
- 退出码非零 → 红 ❌ + stderr 末尾 N 行
- 退出码 0 → 绿 ✅
- 同时检测 `~/.teamagent/postinstall.log` 中 `stage=install-user-hook exit=1` 模式，配合报错

### 验收（V4 — 项目铁律 docs/feature-verification.md）
- 单元测试：mock Spawner，断言 Windows 平台 spawn 选项含 `shell: true`
- 集成测试（chaos）：临时 rename optional dep 目录后 spawn 真 hook，断言 exit 0
- 真机验证：报告人在出问题的 Windows 机器上 reinstall → `teamagent doctor` 见红 → 跑 spawn 修复后再 doctor 见绿 → `analyze --commit` 不再 `failed=N`
- Judge harness：`docs/plans/2026-05-11-issue-280/judge.md`（§V1 RUN / §V2 DUMP / §V3 READ），dump 三个 JSON（单元测试、chaos hook 退出、doctor 报告）让独立 LLM 判 PASS/FAIL
