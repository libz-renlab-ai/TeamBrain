# Daily summary feature (issue #371)

> **Source of truth for product shape**: [issue #371 grill comment](https://github.com/libz-renlab-ai/TeamBrain/issues/371#issuecomment-4437846103)
> + [`docs/adr/0014/371.md`](../adr/0014/371.md).

## What it does

The operator types one of a handful of Chinese / English daily-summary
phrases (or the `/daily` slash command) into any Claude Code window. The
TeamAgent UserPromptSubmit hook:

1. Recognizes the phrase via a three-layer matcher.
2. Scans `~/.claude/projects/<encoded-cwd>/*.jsonl` for sessions whose
   `mtime` falls inside today's **local-time** window (`[midnight, now)`).
3. Decodes each `<encoded-cwd>` back to its absolute path, then folds any
   `.codex/worktrees/<task>` or `.claude/worktrees/<task>` paths back to
   their host repo so a project shows up once even when the operator has
   five worktrees open.
4. Aggregates per-project (LLM-free): session count, user-turn count,
   assistant character count, first / last user-turn excerpt, tools used,
   whether any of the merged sessions came from a worktree.
5. Composes an `additionalContext` markdown block instructing Claude to
   write the actual `一句话/项目` summary in its own response.
6. Archives a raw activity dump to
   `${TEAMAGENT_HOME-~/.teamagent}/daily/<YYYY-MM-DD>.md` (overwrite per
   re-invocation).

TeamAgent itself makes **zero LLM calls** in this path. The summary text the
operator sees is generated by their own Claude Code window using their own
subscription / API key — that matches grill §2 explicit constraint.

## Trigger phrases

Whitelist (substring match; case-sensitive):

- `总结一下今天的日报`
- `总结今天的日报`
- `今日日报`
- `生成日报`
- `daily summary today`
- `today's daily summary`

Slash command (prefix match): `/daily` / `/daily --archive` / `/daily\n...`.

Operators can extend the whitelist via env var:

```bash
export TEAMAGENT_DAILY_TRIGGERS="周报,end-of-day"
```

Disable entirely with:

```bash
export TEAMAGENT_DAILY_DISABLED=1
```

## CLI surface

```text
teamagent daily [--projects-root=PATH] [--cwd=PATH] [--archive]
                [--format=json|context] [--help]
```

- `--help` prints a canonical JSON help schema (matches `docs/feature-verification.md`).
- `--format=json` (default) emits the same per-project `ProjectDigest` list
  the hook builds internally — useful for piping into `jq` or a fixture diff.
- `--format=context` emits the markdown the hook would inject.
- `--archive` writes `${TEAMAGENT_HOME-~/.teamagent}/daily/<date>.md`.
- `--projects-root` is intended for fixture / harness scans; defaults to
  `~/.claude/projects`.

## What is NOT in scope

Issue #371 MVP explicitly leaves these to follow-up issues (per grill §3):

- Manager / cross-member aggregation (layer B).
- Historical dates (`昨天的日报`, arbitrary date).
- Cross-machine aggregation (same operator on two laptops).
- Rich formatting (tables, PR references, commit links).
- Slack / email / 飞书 push.
- Sensitive-information redaction.
- Real LLM-fallback intent check via `claudefast` / `ANTHROPIC_API_KEY` —
  the matcher ships an injectable seam stub (`intentChecker`) and gracefully
  degrades to "whitelist + slash only" when no checker is wired (grill §4).
