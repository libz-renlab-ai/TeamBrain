## Grill sections that touch #306 (verbatim)

# 12. #306 / #326：statusline 是同一 presence state 的本地视图

## Grill 问题

本地 statusline 和 leader green light 是什么关系？

## 可选答案

A. 完全无关
B. 同一 presence state 的两个视图
C. leader green light 驱动 statusline
D. statusline 只显示美观文本
E. 暂不接入

## 裁决

选 **B**。

#306 只说用户想要更美观的状态栏、内容需要优化；#326 是 #122 RESCOPE 的实现半部分，落地范围包括 landing → init → Claude Code statusline，并要求 12 项落地和 `/review` 通过。citeturn138076view3turn138076view8

所以 statusline 不应该独立发明一套状态。

同一状态：

```txt
presence_state:
  active
  idle
  offline
  error
```

本地 statusline 显示：

```txt
TeamAgent: active
Project: TeamBrain
Queue: 0 pending
Upload: ok
Binding: GitHub linked
```

leader app 显示：

```txt
Alice / TeamBrain: green active
Bob / TeamBrain: yellow idle
Carol / TeamBrain: red error
```

不要让 statusline 显示日报、leader 视图、incident 流程。它只是开发者本机的 agent 健康状态。
