### 范围
**做**：让"语义匹配"开箱即用 = 把 `@xenova/transformers@^2.17.0` + `onnxruntime-node@1.14.0` 放回 `packages/teamagent/package.json` 默认依赖，**同时**新建一个**常驻 embedder daemon**让所有 hook 共享已加载的模型。

**不做（v1 出范围）**：
- 量化/换更小模型（v2 优化项）
- HTTP localhost token 鉴权（YAGNI；只绑 127.0.0.1）
- 模型缓存清理（v2）
- 原 issue 中的 Plan B（首次询问）/ Plan C（banner）/ Plan D（拆 npm 包）

### 实测背景（为什么必须造 daemon）

单纯把两个包放回 `package.json` 会灾难（已实测，见 `.fastprobe/` benchmark）：

| 场景 | 实测数据 |
|------|---------|
| 单次 PreToolUse 冷加载 | **3-4 秒** + 650MB RSS |
| 5 个并发 hook | **3.3GB RAM peak**（8GB Mac OOM） |
| Claude Code 一次对话（5-30 次工具调用） | 累计 **15-120 秒卡顿** |

issue-189 fix（`d009d71`）只解决了 Stop hook orphan/OOM 与 90s fetch hang，**未解决 PreToolUse 每次冷加载**。本 PR 才是病根的解。

### 架构

\`\`\`
SessionStart hook
   ├─ 读 ~/.teamagent/.embedder-state.json
   ├─ 若 status=running 且 pid 活 → refcount++
   └─ 否则 → spawn detached bin-embedder.cjs

bin-embedder.cjs（常驻 daemon）
   ├─ 加载 XenovaRuleEmbedder（仅一次）
   ├─ http.createServer().listen(0)  // 随机端口
   ├─ 写 port/pid/members 到 state file
   ├─ POST /embed { text } → { vector }
   └─ POST /shutdown → refcount--, 归零则 exit

PreToolUse / Stop hook
   ├─ 读 state file 拿端口
   ├─ POST localhost:port/embed (timeout 200ms)
   ├─ 成功 → 跑 semanticMatch
   └─ 失败 → 走现有 useLegacy=true 分支 + 异步 spawn daemon

SessionEnd hook
   └─ POST localhost:port/shutdown
\`\`\`

### 失败模式

| 失败 | 行为 |
|------|------|
| daemon HTTP 连不上 | 钩子立即 \`useLegacy=true\`，**异步** spawn daemon（不阻塞当前 hook 响应） |
| daemon 启动失败（端口/模型损坏） | state file \`status=failed\`，钩子永久 legacy 直到下次 SessionStart 重试 |
| state file 不存在 | 钩子走 legacy，下次 SessionStart 触发 spawn |
| pid 死了但 state 未更新 | 钩子 \`process.kill(pid, 0)\` 验活，死了重新 spawn |
| 多个 SessionStart 并发 spawn | PID lock（\`.embedder.lock\` 文件 + atomic rename）；后到的 spawn 复用先到的 daemon |
| 模型下载阶段（首装 5min 内） | 沿用现有 \`warmup-state.ts\` 的 ready-gate；status≠ready 直接 legacy |

### 验收（/review 判 PASS 标准）

1. \`packages/teamagent/package.json\` 在 \`dependencies\`（**非** \`optionalDependencies\`）含两个 vector 包
2. 首次 SessionStart 后 \`~/.teamagent/.embedder-state.json\` 出现 \`status=running\`
3. 同一 Claude Code 会话内多次 PreToolUse **共享同一个 daemon 进程**（pid 不变）
4. 关闭最后一个 Claude Code 后 daemon 在 5 秒内退出（state file 清理或 \`status=exited\`）
5. 手动 \`kill <daemon-pid>\` 后下一次 hook **响应 < 100ms**（legacy 兜底）+ 异步重启 daemon
6. 5 个并发 hook embed，**总 RSS < 800MB**（共享 daemon 验证）
7. \`TEAMAGENT_MATCHER=legacy\` 仍能完全 bypass daemon
8. ADR 0001 的 30s install promise 仍满足（postinstall.mjs 仍然 detach 模型下载）
9. \`pnpm test\` 全绿
10. 全程**不引入** socket / named pipe / Unix socket（HTTP + file 状态文件二件套）
