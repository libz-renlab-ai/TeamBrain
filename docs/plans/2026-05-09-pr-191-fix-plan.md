# PR-PLAN — fix `docs/features/claude-code-action.md` doc gap (PR #191)

## ① Task description

Doing:

- Add a "Prerequisites — GitHub App install" section near the top of
  `docs/features/claude-code-action.md` documenting that
  `CLAUDE_CODE_OAUTH_TOKEN` alone is insufficient; the **Claude Code
  GitHub App** at `https://github.com/apps/claude` must be installed on
  the repo or the action 401s during the OIDC → app-token exchange.
- Add a "Troubleshooting" mini-section listing the literal 401 error
  string ("`App token exchange failed: 401 Unauthorized — Claude Code
  is not installed on this repository...`") so future readers searching
  the failure can find the fix.
- Append a "Post-PR observation" entry to
  `docs/plans/2026-05-09-docs-install-github-app-report.md` recording
  the live failure on PR #191 itself as the signal that drove this fix.

Not doing:

- Installing the GitHub App. That's a one-time browser-side OAuth flow
  the human runs at `https://github.com/apps/claude`; not something the
  agent can do from CLI.
- Rewriting the rest of the doc. The other sections are factually
  correct; only the auth/prereq wording was incomplete.
- Re-running `/install-github-app`. The local install said "complete";
  the gap is on the GitHub-side App authorization, which is a separate
  step the doc must now name.
- Forking the failure into a follow-up issue. PR-PLAN rule applies.
