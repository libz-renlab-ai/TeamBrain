# 6. #371 日报：GitHub-first，不是 prompt-first

## Grill 问题

日报的主数据源是什么？

## 可选答案

A. prompt 原文
B. Claude/Codex session summary
C. GitHub activity
D. audio transcript
E. GitHub-first，AI/audio 作为辅助 evidence

## 裁决

选 **E，但主源是 GitHub**。

#371 的需求是“员工每天使用完 Claude 后，统一汇总他们在多个并行项目中的操作，通过一句话总结当天工作内容，形成每日工作汇报”。它说的是“多个并行项目中的操作”和“一句话总结当天工作内容”，不是“把 prompt 摘要发给老板”。citeturn138076view9

所以日报结构应该是：

```txt
主记录：
  member × project daily summary

项目首页：
  project daily summary

成员视角：
  member daily summary，可选

明细锚点：
  Issue > PR > Branch > Commit > AI Session
```

示例：

```txt
Alice / TeamBrain:
  今天推进 Codex hook 初始化幂等与 adapter 分离，已完成配置 merge 策略讨论，尚未合并 PR。

Bob / TeamBrain:
  今天排查 Windows audio 默认设备问题，确认应默认麦克风并提供 --device 逃生口。
```

日报不是：

```txt
Alice 今天问了 Claude 38 次。
```

日报应该是：

```txt
Alice 今天在 TeamBrain 的 #291 上推进 init --target=both 的幂等 hook 安装方案。
```
