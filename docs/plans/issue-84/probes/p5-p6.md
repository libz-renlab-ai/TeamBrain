## P5 — AI-Slop Anti-Pattern Library

**Source**: `.fastprobe/issue84/p5.json`

### 8 Must-Avoid Patterns

| id | Pattern | Bad Example | Good Example | Why |
|----|---------|-------------|--------------|-----|
| 1 | 抽象渐变宇宙背景+漂浮光点 | 深紫/蓝渐变+模糊光斑+AI晶体+"The future of AI is here" | 深色主题+橙色lobster主题色，mascot直接可见 | 宇宙/水晶/大脑图形是AI slop视觉原型 |
| 2 | 无作者名的虚假推荐语卡片 | 'Amazing product! ⭐⭐⭐⭐⭐' 署名 'Happy Customer' | 真实用户头像+真实姓名+职务+GitHub链接 | 匿名假推荐是最低配信任伪造 |
| 3 | 堆砌营销热词的hero文案 | 'Revolutionize Your Workflow with AI-Powered Synergy' | 'Meet your lobster' + 'Your digital employee' | 热词是大模型批量生成的标志性语言 |
| 4 | AI生成的通用feature图标 | 大脑/灯泡/齿轮配'Smart Automation'/'Intelligent Insights' | 实际产品截图+真实集成logo（GitHub/Discord等） | 通用图标是AI slop的视觉占位符文化 |
| 5 | 全页只用一种语言叙事 | 'We are dedicated to...', 'Our platform is built to...' | 大量社区用户testimonial+community showcase | 企业独白制造距离感；用户声音可信十倍 |
| 6 | 模糊产品定位语 | 'The All-in-One AI Platform for Modern Teams' | 'AI coding agent/digital employee'+'Your personal OS' | 模糊定位是AI slop保护色 |
| 7 | Markdown分隔线/等宽字体滥用 | Hero下用===或---分隔线，充斥#Section残留 | 用字体大小/颜色/间距表达结构 | Markdown等宽字符是AI生成内容的视觉签名 |
| 8 | 无限滚动feature列表+巨型hero CTA | 3-4屏堆feature+占半屏宽的紫色渐变'Get Started Free →' | 密集但有呼吸感的卡片布局，CTA融入内容流 | '紧迫感操控'套路，用户已免疫 |

### OpenClaw Strengths

1. 具体mascot（lobster/🦞）建立强记忆点，避免抽象logo
2. 社区真实用户testimonial优先于企业营销文案
3. 清晰功能定位语言（'digital employee'、'personal OS'）
4. 真实集成生态展示（GitHub、Discord logo等）
5. playful语气配合meme文化自嘲（'a dude and a repo'）

## P6 — Lighthouse a11y ≥ 90 / SEO ≥ 90 Baseline

**Source**: `.fastprobe/issue84/p6.json`

### a11y Requirements (10 rules)

| id | Rule | Lighthouse Audit |
|----|------|-----------------|
| aria-valid-attr | 所有ARIA属性必须合法 | aria-valid-attr |
| button-name | 按钮必须有可访问名称 | button-name |
| color-contrast | 前景/背景对比度 ≥ 4.5:1 | color-contrast |
| document-title | `<title>` 不能为空 | document-title |
| form-field-label | 每个表单控件必须有关联`<label>` | label |
| html-has-lang | `<html lang="...">` 必须存在且非空 | html-has-lang |
| image-alt | `<img>` 必须有alt（含空alt对装饰图） | image-alt |
| link-name | 链接文本必须可被辅助技术识别 | link-name |
| meta-viewport | `<meta name="viewport">` 不能限制缩放 | meta-viewport |
| skip-link | 提供可跳至内容的skip link | bypass |

### SEO Requirements (9 rules)

| id | Rule | Lighthouse Audit |
|----|------|-----------------|
| canonical | `<link rel="canonical">` 存在 | canonical |
| charset | `<meta charset="UTF-8">` 在`<head>`最前 | document-charset |
| description | meta description存在且50-160字符 | meta-description |
| h1 | 页面有且仅有一个`<h1>` | heading-order |
| hreflang | 多语言站需`<link rel="hreflang">` | hreflang |
| image-alt | img alt文本含关键词 | image-alt |
| invalid-robots | 无noindex/nofollow误置 | robots-txt |
| link-text | 链接文本描述性且唯一 | link-text |
| title | `<title>` 存在且15-60字符，含目标关键词 | document-title |

### Required Meta Tags (12)

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>{页面标题} | {品牌名}（≤60字符）</title>
<meta name="description" content="{50-160字符描述，含核心关键词}">
<meta name="robots" content="index, follow">
<link rel="canonical" href="{绝对URL}">
<meta property="og:title" content="{标题}">
<meta property="og:description" content="{描述}">
<meta property="og:image" content="{图片URL}">
<meta property="og:url" content="{canonical URL}">
<meta property="og:type" content="website">
<meta name="twitter:card" content="summary_large_image">
```
