## Primary grill sections for #296 (verbatim)

# 19. audio 线：#296/#297/#310 必须统一成 `audio` event source

## Grill 问题

录音是个人记忆、项目证据、日报输入，还是异常输入？

## 可选答案

A. 个人记忆
B. 项目证据
C. 日报输入
D. 异常输入
E. audio 是 event source，用途由 plugin 决定

## 裁决

选 **E**。

```txt
AudioRecordingStarted
AudioRecordingStopped
AudioUploaded
AudioTranscriptReady
AudioSummaryReady
```

plugins 决定用途：

```txt
RecordingMemoryPlugin:
  进入 personal/team memory

ProjectEvidencePlugin:
  挂到 project/issue/PR

DailySummaryPlugin:
  可选进入日报

AbnormalDetectorPlugin:
  可选扫描 blocker/risk/stuck
```

#296 说明两个独立子系统都用了 “recording”：一个是 `teamagent recording import|search|show|inject|metrics|benchmark` 的 Recording Memory，另一个是 `teamagent record start|stop|import` 的 digital-twin audio recorder，而且后者还上传到 `/v1/recordings`；issue 明确指出这会让用户混淆。citeturn148789view0turn148789view1

所以命名裁决：

```txt
新命名：
  teamagent audio start
  teamagent audio stop
  teamagent audio import
  teamagent audio devices

API:
  /v1/audio-recordings
  /v1/events

事件：
  AudioRecordingStarted
  AudioTranscriptReady

兼容：
  teamagent record start -> alias to teamagent audio start
  /v1/recordings -> deprecated alias
```
