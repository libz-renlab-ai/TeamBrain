## Grill 问题

app 第一版首页证明什么？

## 可选答案

A. UI 好看
B. leader 不用问人也知道谁在推进什么
C. leader 能发现异常并介入
D. leader 能配置所有 plugin
E. B + C，配置藏在设置页

## 裁决

选 **E**。

首页结构：

```txt
第一屏：
  今日异常 / 需要介入事项

第二屏：
  成员 × 项目 green light matrix

第三屏：
  今日 member × project 一句话日报

侧边：
  plugin 设置 / GitHub 绑定 / agent install 状态
```

#309 的“花里胡哨界面，然后补后端”不能按字面理解成“先画 UI”。它真正的问题是：小 B leader 打开 app 后，3 秒内能不能看到价值。citeturn138076view5

价值不是：

```txt
我们有 dashboard
```

价值是：

```txt
你今天不用挨个问人。
你知道谁在动，谁卡住，哪个项目需要你介入。
```
