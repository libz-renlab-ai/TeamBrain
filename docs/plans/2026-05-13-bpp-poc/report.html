7. honest scope statement — 这个 PR 没做什么

✓ 本 PR 做的事

  • Spec + Plan 两份完整文档（commit 2bf8bfb + f92947f）
  • Phase 1 全部 6 个任务（commits 89123f3 / 70d409d / 47ad686 / c751508 / 1f5ea76）
  • 24 个单元 + 集成 + e2e 测试全部 PASS
  • Live demo 实测 7 步全绿（HTTP 200 / 400 路径都覆盖）
  • HTML 报告（本文件）+ SVG 数据流动画

⚠ 本 PR 没有做的事（CEO 鸭请注意）

  • AI mining pipeline (Phase 2) —— 这是整个 BPP 唯一真正"新建"的核心。本 PR 只准备好了数据模型和管道入口；行为模式 mining LLM、context-pattern miner、git-skill-diff miner 等都还没写。当前 "BP 来自哪" 的字段全靠手工 POST 上去。
  • 接收方 UI (Phase 3) —— Inbox 3 视图（按人/主题/逐条）、statusline 📬 指示、Slack/email webhook 都还没做。本 PR 只能用 curl 或 fetch 调 API。
  • Lead Console + 撤回 + 强制推送 (Phase 4) —— POST /v1/revoke endpoint 没接、强制推送的 forced_by_lead 字段也只是数据模型占位。
  • 隐私合规 (Phase 5) —— "I AGREE" 弹窗、HTTPS 强制、30 天 transcript 自动清理、audit log hash chain 全部 TBD。当前 /v1/inbox endpoint 任何 LAN 上的人都能查（继承 cc-status 已知风险）。
  • Verify harness (Phase 6) —— tier (a) byte-diff fixture、tier (b) scipy Counterfactual Ablation、tier (c) LLM judge 都没建。当前唯一验证是 vitest 单元 + e2e。
  • 原本要做的 Chrome 截图 + gif —— Chrome 扩展无法访问 localhost 127.0.0.1:9787，实测 Frame is showing error page。改用嵌入式 terminal 块 + SVG <animate> 替代。原始 stdout 完整保存在 evidence/demo-stdout.clean.txt。
